Timely

Say what you need to remember. Timely writes it down.

A voice assistant that sets reminders, tracks the habits you mention and keeps a log of what you did each day. No typing, no forms.

Talk normally. Timely picks the right tool.

Each thing you say maps to a small Python function. Everything is saved on your own computer in a plain JSON file.

  • Remind me to call the bank tomorrow at 9add_reminder
  • What reminders do I have?list_reminders
  • I finished the bank callcomplete_reminder
  • I did a 20 minute walk todaylog_habit
  • How are my habits this week?habit_summary
  • Log that I finished my assignment draftadd_log_entry
  • What did I do today?get_daily_log

Built with the AWS community toolkit

Timely started from the AWS Community Day Johannesburg voice agent tutorial and grew its own tools.

Amazon Nova Sonic
The speech-to-speech model on Amazon Bedrock. It hears you and talks back in real time.
Strands Bidi Agents
Streams audio both ways and calls Python tools when you ask for something.
Kiro IDE
The pair-programmer used to scaffold and debug the project.
Python 3.12 and PyAudio
Reads your microphone and plays the replies through your speakers.

Run it on your machine

You need Python 3.12, an AWS account with Amazon Bedrock access, and a microphone. Headphones work best.

git clone https://github.com/TebohoModiba/timely-voice-assistant.git
cd timely-voice-assistant
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python voice_agent.py

Add your AWS credentials to ~/.aws/credentials and set region = eu-north-1 in ~/.aws/config first. Keep your keys out of Git. The README has the full setup.
